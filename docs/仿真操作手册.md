# new_FPGA 桌面图片仿真操作手册

适用工程：`D:\new_FPGA`  
适用工具：Vivado 2023.2、Miniconda Python、Pillow

## 一、现在的图片格式

转换和仿真过程如下：

```text
桌面 PNG/JPEG/BMP（任意大小、彩色或灰度）
  → 自动纠正照片方向
  → 转8位灰度
  → 缩放/裁剪为640×400
  → input_640x400.raw（RAW8，256000字节）
  → testbench将每个像素左移2位，模拟10位黑白摄像头
  → 完整vision_pipeline运行两帧
  → boxed_640x400.raw（每像素16位小端，512000字节）
  → boxed_result.png
```

testbench 自动发送同一张图两次：第一帧找最大窗口，第二帧显示第一帧算出的框。因此不需要再制作20帧，也不需要手动猜运行多少毫秒。

## 二、一条命令完成全部流程（推荐）

先完全关闭正在使用 `D:\new_FPGA` 的 Vivado 窗口，然后在 PowerShell 执行。关闭窗口可以避免工程文件或仿真目录被占用；一键脚本会在需要时自动重建工程。以桌面 `111.png` 为例：

```powershell
cd D:\new_FPGA
& .\sim\scripts\test_desktop_image.ps1 "C:\Users\Lenovo\Desktop\111.png"
```

脚本自动完成：

1. 普通图片转RAW8；
2. 生成实际输入预览；
3. 调用Vivado运行完整流水线仿真；
4. 将带框RAW10输出转换成PNG。

完成后打开输入和输出：

```powershell
Start-Process D:\new_FPGA\sim\data\output\input_preview.png
Start-Process D:\new_FPGA\sim\data\output\boxed_result.png
```

## 三、图片尺寸处理方式

默认使用 `crop`：保持宽高比、铺满640×400，多出的边缘会被裁掉。

```powershell
& .\sim\scripts\test_desktop_image.ps1 "C:\Users\Lenovo\Desktop\111.png" -Fit crop
```

需要保留完整图片并接受黑边：

```powershell
& .\sim\scripts\test_desktop_image.ps1 "C:\Users\Lenovo\Desktop\111.png" -Fit contain
```

允许图像拉伸变形：

```powershell
& .\sim\scripts\test_desktop_image.ps1 "C:\Users\Lenovo\Desktop\111.png" -Fit stretch
```

```powershell

  .\sim\data\input\input_640x400.raw `
  .\sim\data\output\input_preview.png
```

### 3. 打开工程

```powershell
& "D:\Xilinx\Vivado\2023.2\bin\vivado.bat" `
  D:\new_FPGA\build\vivado\new_fpga.xpr
```

在 `Simulation Sources` 中找到：

```text

```

右键选择 `Set as Top`，然后：

```text

→ Simulation
→ Run Behavioral Simulation
```

不要使用 `Run For 10 ms`。这个testbench会在两帧处理完成后自动 `$finish`，通常仿真时间约5.2 ms。

Tcl Console 应出现：

```text

Detection result: found=..., x=..., y=..., bright_count=...
Frame 1: drawing previous-frame result
PASS: desktop image pipeline simulation completed
```

仿真自动调用 `$fclose` 后，执行：

## 五、调整检测参数

打开：

```text
D:\new_FPGA\modules\vision_pipeline\vision_pipeline_image_tb.sv
```

文件开头有两个真实图片测试参数：

```systemverilog
localparam logic [9:0] THRESHOLD    = 10'd512;
localparam integer MIN_BRIGHT_COUNT = 100;
```

- `THRESHOLD`：灰度达到多少算亮点，范围0～1023；
- `MIN_BRIGHT_COUNT`：20×20窗口至少包含多少个亮点才算找到目标，范围0～400。

桌面图片经过 `RAW8 << 2` 输入，因此原图8位灰度128对应10位数值512。

修改参数后保存文件、关闭旧仿真并重新启动 Behavioral Simulation。批处理脚本每次都会重新编译修改过的源码。

## 六、输出框为什么是黑色

图片仿真中的目标是最亮区域，如果继续画白框，白框可能淹没在目标内。因此 `vision_pipeline_image_tb` 将：

```systemverilog
.BOX_VALUE(10'd0)
```

设置为黑框，便于观察。它只影响仿真参数，不会修改通用框选模块的默认白框设置。

## 七、常见问题

### 报错找不到输入RAW

必须先运行 `image_to_raw.py` 或一键脚本。固定输入路径是：

```text
D:\new_FPGA\sim\data\input\input_640x400.raw
```

### 输出PNG还是上一次的

先检查新RAW输出时间和大小：

```powershell
Get-Item D:\new_FPGA\sim\data\output\boxed_640x400.raw |
  Select-Object Name,Length,LastWriteTime
```

正确的一帧应为512000字节。如果仿真报错退出，新PNG不会生成，旧PNG仍会留在磁盘上。

### 图片中没有框

查看Tcl Console中的：

```text
Detection result: found=0
```

若为0，可以降低 `THRESHOLD` 或 `MIN_BRIGHT_COUNT`。如果为1但框不明显，确认查看的是 `boxed_result.png`，并检查框是否靠近图片边缘。

## 八、固定换图流程

```text
关闭旧仿真
→ 运行 test_desktop_image.ps1 并传入新的桌面图片
→ 查看 input_preview.png
→ 查看 boxed_result.png
→ 记录检测坐标和 bright_count
→ 必要时只调整 THRESHOLD / MIN_BRIGHT_COUNT
→ 用同一图片重新验证
```
