# bounding_box_overlay：目标框绘制

## 功能

`brightest_window` 只负责找出最大亮点窗口的左上角坐标。本模块把该坐标保存下来，并在灰度像素流上画一个矩形边框。

由于最佳位置要到一帧的最后才知道，正常时序是：

```text
第 N 帧：搜索最佳窗口
帧末：brightest_window 输出 result_valid、best_x、best_y
第 N+1 帧：bounding_box_overlay 在保存的位置画框
```

这样不需要缓存整张640×400图像。代价是显示框相对检测结果晚一帧。

## 默认参数

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `PIXEL_WIDTH` | 10 | 灰度像素位宽 |
| `BOX_WIDTH` | 20 | 框的外部宽度，应与搜索窗口宽度一致 |
| `BOX_HEIGHT` | 20 | 框的外部高度，应与搜索窗口高度一致 |
| `BOX_THICKNESS` | 1 | 边框厚度，单位为像素 |
| `BOX_VALUE` | 全1 | 框线灰度；10位时为1023（白色） |

## 两组输入

像素流输入：

| 输入 | 含义 |
|---|---|
| `pixel_data` | 尚未画框的原始10位灰度像素 |
| `pixel_valid` | 当前像素有效 |
| `frame_start` | 当前像素是一帧第一个像素 |
| `line_start` / `line_end` | 当前像素是一行第一个/最后一个像素 |
| `pixel_x` / `pixel_y` | 当前像素坐标 |

检测结果输入：

| 输入 | 含义 |
|---|---|
| `result_valid` | 检测结果更新脉冲 |
| `target_found` | 当前结果是否有效；为0会关闭框线 |
| `best_x` / `best_y` | 最大窗口左上角坐标 |

## 输出

`boxed_*` 是延迟一个时钟周期的灰度像素流和元数据。框线上的像素被替换为 `BOX_VALUE`，框内和框外的其他像素保持原灰度。

`box_active` 仅在当前输出像素属于矩形边框时为1，便于波形调试或后续改成彩色叠加。

## 内部变量

| 变量 | 含义 |
|---|---|
| `saved_target_found` | 保存上一帧是否找到目标 |
| `saved_box_x/y` | 保存上一帧最佳窗口左上角 |
| `box_right_exclusive` | 矩形右边界的下一列，不属于矩形 |
| `box_bottom_exclusive` | 矩形下边界的下一行，不属于矩形 |
| `inside_box` | 当前输入像素位于矩形内部（包括边缘） |
| `on_box_border` | 当前输入像素位于矩形四条边之一 |

## 测试

testbench 使用8×6图像，模拟输入坐标 `(2,1)`、大小4×3的检测结果。矩形周长应有10个像素，仿真还会检查非边框像素未被修改、坐标和行/帧标志仍然对齐。

## 限制

- 本模块画的是固定20×20搜索窗口，不是目标真实轮廓；
- 默认白框在已经饱和的白色区域上可能不明显，可以把 `BOX_VALUE` 改成0画黑框；
- 若目标快速移动，晚一帧显示会产生位置滞后；如需同帧显示，必须缓存整帧后再输出。
