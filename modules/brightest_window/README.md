# brightest_window：二值图最大亮点窗口

## 功能

输入已经是二值化后的单像素流：

```text
0 = 暗像素
1 = 亮像素
```

模块在整帧图像中以1像素为步长移动固定大小的窗口，统计每个窗口中1的数量，并输出亮像素最多的窗口。

这不是原始灰度求和。像素在二值化后，无论原始灰度是513还是1023，都只贡献一个亮像素。

## 默认参数

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `IMAGE_WIDTH` | 640 | 图像宽度 |
| `IMAGE_HEIGHT` | 400 | 图像高度 |
| `WINDOW_WIDTH` | 20 | 窗口宽度 |
| `WINDOW_HEIGHT` | 20 | 窗口高度 |
| `MIN_BRIGHT_COUNT` | 0 | 最少亮像素数；0表示任何窗口都可成为候选 |

20×20窗口的计数范围是0～400，需要9 bit。

## 输入变量

| 输入 | 含义 |
|---|---|
| `binary_data` | 当前二值像素 |
| `pixel_valid` | 当前像素有效 |
| `frame_start` | 当前像素是一帧第一个像素 |
| `line_start` | 当前像素是一行第一个像素 |
| `line_end` | 当前像素是一行最后一个像素 |
| `pixel_x/y` | 当前像素坐标 |

## 输出变量

| 输出 | 含义 |
|---|---|
| `result_valid` | 本帧结果输出脉冲，只持续一个时钟周期 |
| `target_found` | 至少一个窗口满足 `MIN_BRIGHT_COUNT` |
| `best_x/y` | 最佳窗口左上角坐标 |
| `best_bright_count` | 最佳窗口中的亮像素数量 |

默认窗口中心为：

```text
center_x = best_x + 10
center_y = best_y + 10
```

## 工作方法

模块不会一次取出400个像素相加，而是维护滑动计数：

```text
新列计数 = 旧列计数 + 新像素 - 20行以前的像素

新窗口计数 = 旧窗口计数 + 新进入的右列 - 离开的左列
```

默认历史缓存只保存：

```text
20 × 640 × 1 bit = 12800 bit
```

## 选择规则

```text
窗口计数 >= MIN_BRIGHT_COUNT
且窗口计数 > 当前最大值
```

计数相同时保留扫描中先出现的窗口，即更靠上、再更靠左的窗口。

## 当前限制

- 不使用原始灰度；
- 搜索整个画面，没有ROI；
- 窗口固定，不判断目标实际尺寸或长宽比；
- 不使用形态学或多帧稳定性；
- 在每帧最后一个像素处理完成时输出结果。

## 测试

测试使用6×5二值图和2×2窗口，放入一个3亮点干扰窗口和一个4亮点目标窗口。期望找到左上角 `(3,2)`，计数为4。
